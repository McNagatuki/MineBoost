# MineBoost — Minecraft Forge 1.20.1

タグで採掘速度とブロックのドロップ数を変更するサーバー向けMODです。
MOD ID: `mineboost` / バージョン: `1.0.0` / ビルド対象: Forge `47.3.0` / Java 17。
クライアント側に本MODを導入しなくてもよい設計です（サーバーのみで動作）。
新規ポーション、アイテム、通信チャンネルは追加しません。

## ビルド

JDK 17（64bit）をインストールし、`JAVA_HOME` および PATH を設定してください。
`java -version` が 17 を示すことを確認してください。インターネット接続が必要です。

- Windows: `build.bat` をダブルクリック、または PowerShell で `powershell -ExecutionPolicy Bypass -File .\build.ps1`。
- Linux/macOS: `bash build.sh`（curl と unzip が必要）。

初回は公式 Forge MDK から Gradle Wrapper のみを取得し、依存関係をダウンロードします。
既に対応する Gradle 8.x を使用できる場合は `gradle build` でもビルド可能です。
成功時の生成物: `build/libs/mineboost-forge-1.20.1-1.0.0.jar`。
この JAR を Forge 1.20.1 サーバーの `mods` に入れ、起動してください。
ZIP ファイル自体は mods に入れないでください。

サーバーの Forge バージョンに合わせてビルドしてください（`build.gradle` の `forge:1.20.1-47.3.0`）。
新しい Forge でビルドすると、古い Forge のサーバーに存在しないメソッドを使ってしまい、起動時に `NoSuchMethodError` 等で失敗することがあります。

## 使い方

初期設定は採掘速度 2.0 倍、ブロックドロップ 2.0 倍、タグ名は `MB_speed_up` / `MB_drop_up` です。
タグを持っていないプレイヤーには適用されません。
以下のコマンドには OP レベル 2 以上が必要です。サーバーコンソールでは先頭の `/` を省きます。

```mcfunction
/tag @p add MB_speed_up
/tag @p add MB_drop_up
/mineboost speed multiplier 5
/mineboost drop multiplier 3
/mineboost status
```

解除:

```mcfunction
/tag @p remove MB_speed_up
/tag @p remove MB_drop_up
```

タグ名の変更（完全一致、大小文字区別。元のタグを自動で付け替えることはありません）:

```mcfunction
/mineboost speed tag mining_boost
/mineboost drop tag loot_boost
/tag @p add mining_boost
/tag @p add loot_boost
```

`:` を含むタグなどは引用符で囲んでください。倍率は 1〜100、小数可、1 で無効化。
設定は `config/tagboost.toml` に保存し、再起動しても維持されます。
タグを持つプレイヤー全員に同じ倍率が適用されます。タグの追加・削除・変更は即時判定します。

## 仕様と注意点

### 採掘速度

- 採掘速度は通常の計算値（道具、効率強化、採掘速度上昇、疲労などを含む）に倍率をかけます。サーバー側の採掘進捗が完了した時点で、通常の破壊ルートを呼び出します。
- クライアントは倍率を知らないため、サーバーが先にブロックを壊し、結果をクライアントへ送ります。ヒビのアニメーション、腕振り、次のブロックへ移るタイミングはバニラのままなので、実測時間は tick、通信遅延、操作に左右されます。極端な倍率で特に違いが出ます。
- 倍率のせいでサーバーだけが即時破壊・先行破壊した場合は、本人のクライアントにも破壊音と破片エフェクトを送ります（バニラは破壊した本人には送らないため）。

### ドロップ

- ドロップはブロックの loot table で計算された結果を増やします（幸運、シルクタッチ適用後）。元が0個なら0個。小数は端数確率で丸めます（1個×2.5なら2個または3個）。スタック上限に合わせて分割します。
- MOB、チェストの戦利品、釣り、経験値、手動で捨てるアイテム、コンテナから別処理で飛び出す中身は対象外。ブロック loot context を生成するコマンドや他MODの機能は対象になる可能性があります。
- アイテムに BlockEntityTag がある場合は複製しません（中身入りシュルカーボックス等）。
- 高倍率では1ブロックから大量のアイテムエンティティが出るため、サーバー負荷に注意してください（10倍程度までを推奨）。

### 設置したブロックの扱い（増殖対策）

設置→破壊でアイテムを増やせないよう、設置されたブロックはドロップ倍率の対象外です。

- プレイヤー、エンダーマン、設置イベントを出す他MODの機械などが置いたブロックの座標を、チャンクごとに記録します。記録はチャンクと一緒に保存され、再起動後も維持されます。
- 記録された座標のブロックは、壊しても倍になりません。
- 例外として、**育ちきった作物**（小麦・ニンジン・ジャガイモ・ビートルート・ネザーウォート・カカオ・スイートベリー）は植えたものでも倍になります。植えた直後に壊しても増えません。
- ピストン（粘着ピストンでの引き戻し、スライム/ハチミツブロックでの移動を含む）で動かしたブロックは、記録も移動先に引き継ぎます。
- 記録されたブロック（砂、砂利、金床など）が落下した場合は、着地した座標を記録します。自然の砂などの落下は従来通り倍になります。
- 苗木から育った木、丸石製造機の丸石、伸びたサトウキビ・竹など、自然に生成・成長したブロックは倍になります。

注意:

- 本MODの導入前に設置されたブロックには記録がないため、倍になります。
- `/setblock`・`/fill`・`/clone` 等のコマンド、ストラクチャーブロック、WorldEdit、設置イベントを出さない他MODの機械、ディスペンサーで置いたブロックは記録されません。
- 農民の村人が植えた作物は記録されません。

### 除外タグ `mineboost:no_boost`

このブロックタグに含まれるブロックは、設置記録に関係なく常に倍になりません。設置記録の取りこぼしに対する保険です。
初期値は `#minecraft:shulker_boxes`（シュルカーボックス）と `#minecraft:anvil`（金床）です。
データパックで `data/mineboost/tags/blocks/no_boost.json` を用意すると追加できます（`"replace": true` で置き換え）。

### その他

- 採掘速度とドロップの倍率は独立しています。クリエイティブ/スペクテイターには適用しません。
- 独自のステータス効果アイコンや `/effect` 対応はありません。サーバーのみで管理するパッシブ効果です。
- Forge の BreakEvent、採掘制限、到達距離等を尊重する設計です。他MODとの順序・互換性は未検証です。

## 動作確認チェックリスト

Forge 47.3.0 サーバーでビルド・基本動作を確認済みです。他の環境や設定に変更した場合は、以下をテスト用ワールドで確認してから本番導入してください。

1. サーバーと同じ Forge バージョンで起動し、MODなしのクライアント（サーバーの他MOD要件を満たすもの）から接続する。
2. サバイバルでタグなし、速度のみ、ドロップのみ、両方の4条件を比較する。
3. 通常のツルハシで石、鉱石、黒曜石、素手で破壊不可のものを試す。高倍率で鉄・ネザライトのツルハシを使い、破壊音が鳴ることを確認する。
4. 幸運・シルクタッチ、倍率2.5、64個超、BlockEntityTag 付きアイテムを試す。
5. 採掘中に操作中断・ターゲット変更・距離超過・タグ削除を試す。保護範囲では破壊できないことを確認する。
6. 設置したブロック（ダイヤモンドブロック、原木、干草の俵など）を壊して倍にならないこと、自然のブロックは倍になることを確認する。
7. 作物を植えてすぐ壊すと増えず、育ちきってから壊すと倍になることを確認する。
8. 設置したブロックをピストンで押す・粘着ピストンで引く、設置した砂を落とす、の後に壊して倍にならないことを確認する。
9. 死亡・ログアウト・ワールド移動後、再起動後に設定・タグ判定・設置記録を確認する。
10. 他MODがある場合は採掘・保護・loot modifier・ブロック設置の互換性を確認する。
